# Student Performance Classification

**Author:** Akash Patel

---

## 📖 Project Description

This project analyzes student data to uncover factors that influence academic performance. It covers the full data-science workflow:

1. Data cleaning & preprocessing  
2. Exploratory Data Analysis (EDA) with visualizations  
3. Statistical analysis of performance drivers  
4. Machine-learning model training & evaluation  

---

## 🚀 Features

- **Data Cleaning & Preprocessing**  
  Handle missing values, encode categorical features, scale numeric variables.  
- **Exploratory Data Analysis (EDA)**  
  Visualize distributions, correlations, and trends using histograms, boxplots, heatmaps.  
- **Statistical Tests**  
  Assess significance of factors (e.g. t-tests, ANOVA).  
- **Machine-Learning Models**  
  Train and compare classifiers (e.g. Logistic Regression, Random Forest, SVM) to predict student outcomes.  
- **Model Evaluation**  
  Report accuracy, precision, recall, F1-score, and ROC-AUC.
